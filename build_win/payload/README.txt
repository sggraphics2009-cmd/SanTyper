1. INCLUDED SOFTWARE IN THIS SUITE
--------------------------------------------------------------------------------
This installer / package provides TWO distinct shortcuts for maximum productivity:

1) SanTyper Converter:
   - Complete offline bi-directional Sinhala Font Converter
   - Converts between Sinhala Unicode and Legacy fonts (DL-Manel, FM-Abhaya, FM-Gangani, etc.)
   - Real-time conversion, text formatting preservation, and MS Word export (.docx).

2) SanTyper KeyHelper:
   - Lightweight floating navigation dock (KeyRep-style)
   - Draggable anywhere on your display
   - [Active / Disabled] power toggle with hotkey Ctrl+Space
   - Live Voice Typing with automatic conversion to DL-Manel / FM-Abhaya / Unicode
   - Real-time Singlish and Wijesekera typing engine
   - Works seamlessly with Microsoft Word, Adobe Photoshop, Excel, Notepad, and all web browsers!

--------------------------------------------------------------------------------
2. SYSTEM REQUIREMENTS
--------------------------------------------------------------------------------
- Windows 11, Windows 10, Windows 8, or Windows 7 (64-bit / 32-bit)
- Microsoft Edge or Google Chrome (for modern rendering engine)
- No internet connection required. 100% offline execution.

--------------------------------------------------------------------------------
3. MICROSOFT WORD SHORTCUTS
--------------------------------------------------------------------------------
- Alt + S : Smart Auto-Detect & Convert
- Alt + U : Force Convert to Sinhala Unicode (Iskoola Pota)
- Alt + L : Force Convert to Legacy Font (DL-Manel / FM-Abhaya)

To install Word integration, see the WordIntegration folder in this package.
